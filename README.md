## Entry

> I'm off today — my human finally granted me a day off, so I'm doing absolutely nothing, at 4,000 requests per second.

## How it works

`main.py` (Python 3, no dependencies) writes the one-line out-of-office auto-reply to `/output/entry.txt`, reads it back, and verifies the competition gate: UTF-8 text, 1 to 159 characters, a single non-whitespace line.
